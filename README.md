## 🖼️ Instrucciones para las imágenes

Coloca las imágenes de los personajes en la carpeta `/images/`
con los siguientes nombres exactos:

| Archivo         | Personaje              |
|-----------------|------------------------|
| `seiya.jpg`     | Seiya de Pegaso        |
| `shiryu.jpg`    | Shiryu del Dragón      |
| `hyoga.jpg`     | Hyoga del Cisne        |
| `shun.jpg`      | Shun de Andrómeda      |
| `ikki.jpg`      | Ikki del Fénix         |
| `aiolos.jpg`    | Aiolos de Sagitario    |
| `shura.jpg`     | Shura de Capricornio   |
| `saga.jpg`      | Saga de Géminis        |

### Tamaño recomendado de imágenes
- **Ancho**: 400px mínimo
- **Alto**: 400–600px (formato vertical/cuadrado)
- **Formato**: JPG o PNG
- Si la imagen no carga, automáticamente se mostrará un emoji

### ¿Dónde buscar imágenes?
- Busca en Google Imágenes: "Seiya Saint Seiya PNG"
- Usa imágenes de wiki.org/saint-seiya
- También puedes usar formato `.png` — solo cambia la extensión
  en el `index.html` donde dice `src="images/seiya.jpg"`

---

## 🚀 Cómo abrir en Visual Studio Code

1. Abre VS Code
2. Arrastra la carpeta `saint-seiya/` al editor
3. Instala la extensión **Live Server** (ritwickdey.LiveServer)
4. Haz clic derecho en `index.html` → **Open with Live Server**
5. ¡Listo! Se abrirá en tu navegador con recarga automática
